# Issue and Contribution Guidelines / 이슈·기여 원칙

This repository distributes proprietary PCssak Jamak binaries and public documentation and tracks user reports. It is not the application source repository. Source-code pull requests for Jamak are not accepted here.

Documentation corrections, safely reproduced bug reports, and focused feature requests are welcome. Search existing issues first, use synthetic media or subtitles, describe the expected and actual result, and remove personal paths, filenames, media content, customer data, secrets, credentials, license keys, and confidential work. Exploitable details must use the private route in [SECURITY.md](SECURITY.md).

AI may help prepare a report or documentation correction, but the submitter must personally verify every factual claim, reproduction step, and proposed wording. Do not submit speculative, duplicate, bulk-generated, or untested issues.

Do not upload third-party media, code, text, screenshots, models, or other material unless you have the right to share it publicly. A documentation contribution does not change the proprietary license of Jamak or grant access to its private source.

## 한국어

이 저장소는 PCssak Jamak 독점 바이너리와 공개 문서를 배포하고 사용자 제보를 관리합니다. 애플리케이션 소스 저장소가 아니며 Jamak 소스 코드 Pull Request는 받지 않습니다.

문서 오류 수정, 안전하게 직접 재현한 버그 제보와 범위가 분명한 기능 제안은 환영합니다. 기존 이슈를 먼저 검색하고, 합성 미디어·자막을 사용하며, 기대 결과와 실제 결과를 적고, 개인 경로·파일명·미디어 내용·고객 자료·비밀정보·자격증명·라이선스 키와 회사 비밀을 제거하세요. 악용 가능한 내용은 [보안 정책](SECURITY.md)의 비공개 경로를 사용해야 합니다.

AI로 제보나 문서 수정을 도울 수 있지만 모든 사실, 재현 단계와 제안 문구는 제출자가 직접 확인해야 합니다. 추측성·중복·대량 생성·미검증 이슈를 등록하지 마세요.

공개할 권리가 없는 제3자 미디어·코드·문구·화면·모델이나 다른 자료를 올리지 마세요. 문서를 기여해도 Jamak의 독점 라이선스가 바뀌거나 비공개 소스에 접근할 권리가 생기지 않습니다.
