# 알려진 한계

[English](KNOWN-LIMITATIONS.md)

## 무료 얼리액세스 상태

- Jamak v0.1.0은 1.0 이전 무료 얼리액세스입니다. 정식 버전 전까지 기능·화면·번역·구성요소
  출처·모델 지원·파일 동작·시스템 요구사항이 바뀔 수 있습니다.
- 발견되지 않은 오류, 충돌, 성능 문제, 전사 오류, 오역, 자막 시간 오류, 렌더링 차이와
  호환성 문제가 남아 있을 수 있습니다.
- 1인 운영 지원에는 응답·수정·업데이트·장기 지원 기한 보장이 없습니다.
- 현재 무료라는 사실은 향후 1.0 출시, 가격, 결제 방식, 기능 영구 유지, 업데이트 일정이나
  계속 배포를 약속하지 않습니다.

## Windows와 설치

- 공개 빌드는 x64 전용입니다. 32비트 Windows, Windows on ARM 네이티브·에뮬레이션,
  Windows S 모드, Windows Server, macOS, Linux와 Wine은 지원하지 않습니다.
- 현재 지원 중인 Windows 11 Home/Pro x64를 권장합니다. Windows 10 22H2 x64는 제한적인
  얼리액세스 호환 범위일 뿐이며 해당 기기가 적용 가능한 ESU에 포함되지 않으면 Microsoft의
  일반 지원 범위 밖입니다.
- 빌드나 시작 성공만으로 모든 Windows 업데이트·GPU·드라이버·코덱·미디어 컨테이너·보안
  제품·언어·정책·저장장치 조합과 호환됨을 뜻하지 않습니다.
- v0.1.0 설치기는 Windows Authenticode 미서명이므로 알 수 없는 게시자, SmartScreen,
  Smart App Control 또는 조직 정책 차단이 나타날 수 있습니다. 보안 장치를 끄지 마세요.
- 현재 사용자 설치는 일반적으로 관리자 권한이 필요하지 않습니다. 관리형 환경에서는
  WebView2·런타임·정책·선택 구성요소에 관리자나 IT 승인이 필요할 수 있습니다.

## 전사와 번역

- 음성 인식과 AI 번역은 확률적입니다. 발화를 빠뜨리거나 없는 문구를 만들고 화자·언어를
  혼동하며 이름·전문용어를 오역하거나 부적절한 문구를 만들 수 있습니다.
- 짧고 시끄럽거나 발화가 겹치고 억양·노래·혼합 언어가 있는 오디오에서는 자동 언어 감지와
  영어 방향 번역이 정확하다고 보장할 수 없습니다.
- 로컬 모델 결과는 모델·양자화·프롬프트·용어·언어쌍·메모리·하드웨어에 따라 달라집니다.
  큰 모델도 정확성을 보장하지 않습니다.
- 게시, 접근성, 법률·의료, 교육, 고객 납품이나 중요한 업무에 쓰기 전 사람이 검수해야 합니다.

## 자막 편집·미리보기·내보내기

- 글꼴 설치 여부와 대체 글꼴, 줄바꿈, 해상도, 배율, 컨테이너 타임스탬프, 코덱과 재생기
  차이 때문에 미리보기와 내보내거나 번인한 결과가 다를 수 있습니다.
- SRT·VTT는 모든 ASS 스타일·카라오케 기능을 보존하지 않습니다. 형식을 바꾸면 지원하지
  않는 정보가 사라질 수 있습니다.
- 실행 취소·다시 실행·복구 세션·안전 저장은 위험을 낮추지만 백업·버전 관리나 운영체제·
  저장장치·전원·외부 프로그램 장애 뒤의 복구 보장이 아닙니다.
- 원본 미디어와 중요한 자막을 별도 검증된 백업에 보관하고 이전 결과를 지우거나 교체하기
  전에 실제 내보낸 파일을 확인하세요.

## 영상 처리와 외부 구성요소

- 영상 번인은 고정 BtbN 상위 릴리스에서 직접 받는 선택형 FFmpeg 빌드를 사용합니다.
  v0.1.0에는 FFmpeg를 동봉하거나 PCSSAK이 미러링하지 않습니다.
- 손상 파일, 미지원 코덱, 특이한 타임스탬프, 가변 프레임률, 보호 미디어, 큰 해상도, 저장
  공간 부족, 하드웨어·드라이버 한계로 디코딩·인코딩이 실패할 수 있습니다.
- H.264 출력 기능이 있다는 사실만으로 모든 사용자 프로젝트의 특허·라이선스·납품·지역
  의무가 해결되는 것은 아닙니다.
- CPU와 CUDA 패키지는 호환성·다운로드 크기·메모리·속도·백신 탐지 위험이 다릅니다.
  v0.1.0은 Intel·AMD GPU 가속을 지원하지 않습니다.

## 개인정보와 네트워크 경계

- 미디어·자막 문구·프롬프트·전사·번역·생성 결과는 사용자 PC에서 처리되며 PCSSAK 처리
  서버로 보내지 않습니다.
- 이는 Jamak이 네트워크를 전혀 사용하지 않는다는 뜻이 아닙니다. 사용자가 선택한 구성요소
  다운로드, 업데이트 확인·승인 다운로드, 필요한 WebView2 전달, 사용자가 연 웹·이메일은
  GitHub·Hugging Face·Microsoft 또는 표시된 다른 제공자에 연결할 수 있습니다.
- 해당 제공자는 자신의 약관에 따라 IP 주소·요청 시각·URL·사용자 에이전트 같은 일반 연결
  메타데이터를 독립적으로 처리할 수 있습니다.
- 공개 GitHub Issue나 이메일은 로컬 처리 경계 밖입니다. 미디어 내용·자막 문구·개인 경로·
  파일명·고객 자료·자격증명·회사 비밀을 제거하세요.

## 업데이트

- Tauri 업데이트 서명은 앱 내부 업데이트 경로에 필수지만 Windows Authenticode와 SmartScreen
  평판과는 별개입니다.
- 최초 v0.1.0 엔드포인트는 `204 No Content`를 유지하며 v0.1.0 앱에 같은 v0.1.0을 제안하면
  안 됩니다. v0.1.1 이상은 릴리스 자산·서명·해시·익명 다운로드·실제 설치 업그레이드를
  독립 검증한 뒤에만 제공합니다.
- 업데이트 서비스를 사용할 수 없으면 설치 앱을 바꾸지 않고 안전하게 실패해야 합니다.
  수동 업데이트는 공식 릴리스 페이지만 사용하세요.
