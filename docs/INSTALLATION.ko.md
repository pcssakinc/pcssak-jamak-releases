# PCssak Jamak 설치 및 업데이트

[English](INSTALLATION.md) · [시스템 요구사항](../SYSTEM_REQUIREMENTS.md) · [알려진 한계](KNOWN-LIMITATIONS.ko.md)

이 안내는 Windows x64용 무료 얼리액세스에 적용됩니다. Jamak은
[공식 제품 페이지](https://pcssak.co.kr/jamak) 또는 이 저장소의
[최신 릴리스](https://github.com/pcssakinc/pcssak-jamak-releases/releases/latest)에서만 내려받으세요.

## 설치 전 확인

1. Windows가 x64이고 문서에 적힌 베타 범위에 포함되는지 확인합니다.
2. 같은 릴리스에서 `PCssak-Jamak-Beta-Windows-x64-Setup.exe`와 `SHA256SUMS.txt`를 받습니다.
3. 설치기의 SHA-256을 공개 값과 비교합니다.
4. 중요한 미디어와 자막 파일은 별도 위치에 백업합니다.
5. SmartScreen, Microsoft Defender, Smart App Control이나 다른 보안 제품을 끄지 않습니다.

v0.1.1 설치기는 Windows Authenticode로 서명되지 않았습니다. 따라서 내려받은 파일의
SHA-256이 공식 값과 같아도 Windows에 **알 수 없는 게시자** 또는 평판 경고가 나타날 수
있습니다. 해시는 공개 파일과 바이트가 같음을 확인할 뿐 코드 서명 인증서나 악성 코드 부재
보증이 아닙니다.

## 처음 대화형 설치할 때

정상적인 최초 설치에서는 설치 화면보다 먼저 언어 선택 창이 나타납니다. 지원 설치 언어는
영어, 한국어, 일본어, 중국어 간체, 중국어 번체, 러시아어, 포르투갈어(브라질),
스페인어(라틴아메리카), 독일어, 프랑스어입니다.

설치 언어를 고르고 설치기에 표시된 최종 EULA를 읽은 뒤 동의할 때만 계속합니다. `PCSSAK`은
게시자와 소프트웨어 브랜드 표시명입니다. 정확한 릴리스에 동봉된 최종 EULA가 사용 조건이며,
초안이나 홈페이지 미리보기는 이를 대신하지 않습니다.

Jamak은 **현재 사용자 범위**로 설치합니다. 일반적인 설치와 제거는 관리자 권한을 요청하지
않고 현재 Windows 사용자 영역에 설치됩니다. 다만 조직 정책이나 보안 제품은 미서명 설치기를
차단할 수 있습니다.

## 필수·선택 구성요소

화면에는 Microsoft Edge WebView2 Runtime이 필요합니다. 설치되어 있지 않으면 설치기가
Microsoft 공식 WebView2 부트스트래퍼를 사용할 수 있으며 이때 인터넷 연결이 필요합니다.
일부 선택형 whisper.cpp·llama.cpp 패키지는 Microsoft Visual C++ 2015-2022 x64 런타임을
요구합니다.

FFmpeg, 전사 엔진·모델과 로컬 번역 구성요소는 v0.1.1 설치기에 포함하지 않습니다. 설정에서
필요한 항목만 선택해 설치하세요. Jamak은 그 릴리스에 고정된 상위 배포처에서 파일을 받고
사용 전에 고정 SHA-256을 확인합니다. 대형 모델에는 긴 다운로드 시간, 넉넉한 저장 공간과
메모리, 경우에 따라 GPU 자원이 필요합니다.

## 복구 설치·재설치·업데이트

- 기존 설치 위에 수동으로 다시 설치하면 이전 설치 언어를 유지하고 최초 언어 선택과 EULA를
  반복해서 표시하지 않습니다.
- 앱 내부 업데이트도 업데이트 모드로 실행되어 최초 설치 화면으로 작업을 중단시키지 않습니다.
- Jamak은 설치 버전을 화면에 표시합니다. 고정 PCSSAK HTTPS 엔드포인트에서 더 높은 승인
  버전만 확인하며 조용히 자동 설치하지 않습니다.
- 새 버전이 있으면 사용자가 다운로드와 설치를 시작합니다. 설치 전에 필수 PCSSAK Tauri
  업데이터 서명이 검증되어야 합니다.
- Tauri 업데이터 서명은 Windows Authenticode와 별개입니다. 유효한 업데이트 서명이 있어도
  최초 설치기의 알 수 없는 게시자·SmartScreen 경고는 사라지지 않습니다.
- v0.1.1 엔드포인트는 정확한 릴리스 자산·익명 다운로드·해시·Tauri 서명을 독립 검증할 때까지
  `204 No Content`를 유지합니다. 그 뒤 출시 소유자가 명시적으로 승인한 제한 실운영 시험에서
  설치된 v0.1.0 앱에 v0.1.1을 `200 OK` 메타데이터로 제공해 실제 업그레이드를 시험할 수
  있습니다. 설치·재시작·표시 버전 확인 전까지 결과는 `NOT_RUN`이며, 실패하면 즉시 `204`로
  되돌립니다.

업데이트 확인이 실패하면 설치된 버전을 계속 사용하거나 공식 릴리스 페이지를 확인하세요.
서명 검증을 우회하거나 다른 다운로드 주소로 바꾸거나 재패키징 파일을 설치하면 안 됩니다.

## 제거

Windows **설치된 앱**에서 PCssak Jamak을 제거합니다. 제거기는 로컬 앱 데이터 삭제 선택지를
제공할 수 있지만, 실수로 설정이나 복구 정보를 지우지 않도록 기본값은 유지입니다. 중요한
자막을 내보내고 데이터가 더 이상 필요하지 않은지 확인한 뒤에만 데이터 삭제를 선택하세요.

내려받은 엔진·모델·부분 다운로드, 내보낸 자막, 렌더링 영상, Windows 휴지통 내용과 Jamak
앱 데이터 범위 밖에 저장한 파일은 별도로 확인하거나 제거해야 할 수 있습니다. 이름이
비슷하다는 이유만으로 모르는 폴더를 지우지 마세요.

안전한 문제 해결은 [지원 안내](../SUPPORT.md), 악용 가능한 문제의 비공개 제보는
[보안 정책](../SECURITY.md)을 확인하세요.
